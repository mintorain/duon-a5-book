# 출판 표준 — 원고 정리 기준 · 판권 · 표지 · 도서정보

## 1. 출판용 원고 정리(삭제) 기준

원고 전체를 서브에이전트에게 읽혀 아래 범주만 골라 `deletions.json`에 **원문 그대로**(바이트 일치) 넣는다. 지운 문구는 `출판용_정리_문구.md`에 위치·사유·보관처와 함께 원문 보관한다.

| 범주 | 예 | 처리 |
|---|---|---|
| 편집 메타 | "원고의", "원고에서는…", "본 집필본은…", "출판 전 갱신 기록" 절, 저자 소개 "수록했다" 메모 | 삭제 |
| 개인정보 | 저자 휴대전화 | 삭제(이메일·블로그는 유지), 출판사 내부 보관 |
| 내부 자료 출처 | "(○○ 제공 PRD v2.0, 날짜)", 참고자료의 "○○ 제공" 항목 | 삭제, 출처 기록용 보관 |
| 유지 | 실습 프롬프트의 `[제품명]` 자리표시, 독자용 주의 문구("교육용 가상 예시"), "내레이션 원고" 같은 본문 어휘 | 삭제 금지 |

부분 삭제는 앞뒤 문장이 자연스럽게 이어지는 최소 문자열로(앞 공백·괄호 포함). 삭제 후 `pdf2chapters.py` 검증이 "원문 − 삭제 = 본문"을 자동 확인한다.

## 3. 표지 (힉스필드)

원본 표지를 유지한 채 A5 비율로 재배치할 때:
1. `mcp__claude_ai_higgsfield__media_upload` 로 원본 표지 + DUON 로고 업로드 → curl PUT → `media_confirm`.
2. `generate_image` `get_cost:true` 로 비용 확인(2k·high·2장 = 2.75 크레딧) 후 생성:
   model `gpt_image_2_5`, aspect `2:3`, quality `high`, resolution `2k`, count 2, 두 이미지를 `image_references`로.
3. 프롬프트 요지: "원본 그림·색·문구를 **그대로**, 배치만 세로형으로 재구성(제목 위로 여유, 그림은 잘리지 않게 약간 작게), 모든 문구 원본과 동일, 하단 중앙에 로고용 흰 알약 자리, 6% 안전 여백, 다른 글자 추가 금지". 한글 제목까지 정확히 재현됐다.
4. 생성 로고는 근사치 — 흰 알약 영역을 PIL 로 다시 그리고 실제 로고 PNG(알파 bbox 크롭, 알약 높이의 78%)를 덮어쓴다.
5. `assets/cover.png` 로 넣으면 테마가 A5 안에 통째로(contain) 앉히고 남는 여백을 `cover_bg`(표지 가장자리 실측색)로 채운다. 크롭 금지.

## 4. 도서정보(ISBN·서점 판매정보)

최종 PDF 로 `book-info` 스킬 실행 → `도서정보_{도서명}_{YYYYMMDD}.md`. 판권의 실제 ISBN 을 쓰고, 인용 쪽번호는 **인쇄된 쪽번호**(본문 1쪽 기준). 판매가·종이책 여부는 사용자 확인 후 기입(전자책 단독이면 종이책 "[해당 없음 — 전자책 단독 발행]").
