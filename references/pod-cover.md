# POD 종이책 표지 — 두온 기본 사양과 펼침 표지 조립

2026-10-14 이신우 확정. 종이책(POD)을 낼 때는 따로 말이 없으면 이 사양으로 표지를 디자인한다.

## 1. 기본 사양

| 항목 | 기본값 |
|---|---|
| 표지 용지 | 아르떼 210g, **날개 표지** (앞·뒤 날개) |
| 내지 용지 | 백색모조 100g |
| 인쇄 | 컬러 (내지·표지) |
| 제본 | 무선제본 |
| 판형 | A5 148×210mm (재단 여유 사방 3mm → 낱면 파일 154×216mm) |
| 날개 폭 | 100mm (2026-10-15 이신우 확정, 책마다 `flap_mm` 로 바꿀 수 있음) |

## 2. 책등 폭

```
책등(mm) = 내지 쪽수 ÷ 2 × 0.12 (백색모조 100g 1장) + 0.25 × 2 (아르떼 210g 표지)  → 0.5mm 단위 반올림
```

| 내지 쪽수 | 책등 |
|---|---|
| 100쪽 | 6.5mm |
| 150쪽 | 9.5mm |
| 194쪽 | 12.0mm |
| 250쪽 | 15.5mm |

- 종이 두께는 일반값(모조 100g 0.11~0.12mm)이다. **인쇄소가 알려 준 책등 폭이 있으면 그 값이 우선**이다(`spine_mm` 로 덮어쓴다).
- 책등 6mm 미만이면 글자를 넣지 않는다. 글자는 책등 양쪽 2mm 안쪽에만 둔다.
- 책등 글자는 위에서 아래로 읽히게 한다(한국 서적 관례). 차례: 제목 → 부제 → (공간) → 저자 → 출판사.

## 3. 펼침면 구조 (왼쪽부터)

```
재단 여유 3 | 뒷날개 F | 뒷표지 148 | 책등 S | 앞표지 148 | 앞날개 F | 재단 여유 3
가로 = 6 + 2F + 296 + S  (F=100, S=12 → 514mm)   세로 = 216mm
```

- 앞·뒤표지 낱면 파일(154×216, 재단 여유 포함)은 좌우 3mm를 잘라 표지 칸에 넣는다. 위아래 여유는 그대로 쓴다.
- 날개와 책등 바탕은 표지 가장자리 색과 맞춘다. 날개 글자는 접는 선·재단선에서 5mm 이상 띄운다.
- 앞날개: 저자 소개(공저면 저자별 한 줄). 뒷날개: 시리즈·같은 출판사 도서, 출판사 이름·누리집.
- 뒷표지: 홍보 문구 + 종이책 ISBN 바코드(EAN-13 + 부가기호 EAN-5) + 정가 표기(도서정가제). 바코드는 `zxing-cpp` 로 판독해 숫자를 확인한다.
- 인쇄 파일에는 재단선·접는 선을 넣지 않는다. 확인용 가이드 이미지를 따로 만든다.

## 4. 조립 스크립트

```bash
python ~/.claude/skills/duon-a5-book/scripts/pod_spread.py <책폴더>/POD표지_펼침면.json
```

출력: `<out>.pdf`(인쇄용) · `<out>.png`(300dpi) · `<out>_가이드.png`(접는 선 하늘색·재단선 자홍색·안전 여백 주황 상자).
설정 예시는 『AI는 누가 책임지는가?』 `pdf2-auto/POD표지_펼침면.json`:

| 키 | 뜻 |
|---|---|
| `pages` | 내지 쪽수 (POD 내지 PDF 쪽수) |
| `inner_paper` / `cover_paper` | `백색모조100`(기본) · `백색모조80` · `미색모조100` · `미색모조80` / `아르떼210`(기본) |
| `spine_mm` | 인쇄소 값으로 책등 고정 (없으면 계산) |
| `flap_mm` | 날개 폭 (기본 100) |
| `front` / `back` | 앞·뒤표지 낱면 154×216 (PNG 또는 PDF) |
| `spine` | `title`·`sub`·`authors`·`publisher`·`bg`·`fg`·`sub_fg`·`accent` |
| `front_flap` / `back_flap` | `heading`, `items`([이름, 설명] 또는 문단 문자열), `foot`(아래 줄) |
| `flap_bg` | 날개 바탕색 |

## 5. 확인

- 가이드 이미지로 책등 글자가 접는 선 안에 있는지, 날개 글자가 5mm 여유 안에 있는지 본다.
- 앞표지 원본은 300dpi 이상이어야 한다(154×216 → 1819×2551px). 모자라면 Real-ESRGAN 으로 4배 키운다 (2026-10-15 이신우 지시):
  `~/tools/realesrgan/realesrgan-ncnn-vulkan.exe -i 원본.png -o 원본_업스케일x4.png -n realesrgan-x4plus -s 4`
  (없으면 github.com/xinntao/Real-ESRGAN 릴리스 v0.2.5.0 의 windows zip). 업스케일 뒤 제목·부제·저자 글자를 잘라 확대해 획이 뭉개지거나 바뀌지 않았는지 눈으로 확인한다. 글자 많은 표지는 anime 모델보다 x4plus 가 낫다.
- 인쇄소에 넘길 때 함께 알리는 값: 판형, 내지 쪽수·용지, 표지 용지·날개 폭, 책등 폭, 컬러, 무선제본.

## 6. 디자이너가 준 펼침 표지 다시 조립 (2026-10-19 황혜진 책)

디자이너 펼침 파일이 앞·뒤표지를 **재단 여유 포함 154mm 낱면 그대로 이어 붙여** 오는 경우가 있다(예: 519.1×215.9mm). 접는 자리 안쪽에 재단 여유 3mm 씩이 남아 표지가 6mm 넓고, 책등은 옛 쪽수 기준이다.

- 칸 경계(mm)를 실측한다: 색 경계·접는 선 표시로 뒷날개 | 뒷표지 | 책등 | 앞표지 | 앞날개 x 좌표.
- 표지 칸은 접는 자리 쪽 안쪽 3mm 를 잘라 148mm 로, 날개는 그대로 100mm, 세로 215.9 → 216 으로 늘인다(`show_pdf_page(clip=…, keep_proportion=False)`).
- 책등은 **늘이지 않는다** — 원본 책등 글자를 새 책등 가운데 놓고 남는 폭은 책등 바탕색(원본에서 색 추출)으로 채운다. 책등 폭은 POD 내지 PDF 쪽수에서 계산.
- 바코드 + 정가: `templates/barcode.typ`(투명 바탕, EAN-13+EAN-5; ISBN 없으면 52×30mm "ISBN 바코드 자리" 상자) 를 typst 로 만들어 뒷표지 빈 면에 얹는다. ISBN 이 나오면 `--isbn --addon` 으로 다시 만들고 zxing 으로 판독.
- TrimBox = 사방 3mm 안, BleedBox = 전체.
- 스크립트: `scripts/pod_reassemble.py` (황혜진 책 tools/pod_cover.py 사본 — SRC_* 칸 좌표·SPINE_RGB·BARCODE_AT·INNER 를 책마다 바꾼다)
  `python pod_reassemble.py [--isbn 979… --addon 03810] [--price 15,000] [--spine 11.5] OUT.pdf`
- 출력 파일명에 실제 펼침 크기를 쓰고(`…_펼침_513.5x216_검토본.pdf`), 쪽수가 바뀌면 책등·파일명을 함께 바꾼다. 디자이너에게 바뀐 책등 폭을 알린다.
- 전자책 뒤표지는 같은 원본의 뒷표지 칸(재단 여유 포함 154mm 그대로) + 전자책 정가 바코드.
